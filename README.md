# passo_a passo para mudar imagens no html usando o Sources

Passo a passo para substituir a imagem pela aba Sources

1. Abra o DevTools (F12 ou Ctrl + Shift + I no Windows / Cmd + Option + I no Mac) e vá até a aba Sources (Origens).
2. No menu lateral esquerdo (onde ficam as pastas do site), clique na sub-aba Overrides (Substituições) — se não aparecer, clique na setinha >> ao lado de Page.
3. Clique em + Select folder for overrides (+ Selecionar pasta para substituições), escolha uma pasta vazia no seu computador e clique em Permitir na barra superior do Chrome para dar permissão de acesso.
4. Volte para a sub-aba Page (Página), navegue pelas pastas do site até encontrar o arquivo de imagem desejado.
5. Clique com o botão direito sobre o nome da imagem e selecione Override content (Substituir conteúdo).
6. Abra a pasta que você escolheu no passo 3 pelo Explorador de Arquivos (Windows) ou Finder (Mac). Você verá a estrutura de pastas do site criada lá dentro com o arquivo da imagem original.
7. Substitua esse arquivo pela sua nova imagem, mantendo exatamente o mesmo nome e extensão (ex.: logo.png), e recarregue a página (F5).
